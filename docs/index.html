01 · Know the location

For satellite visibility, the current reference is Abu Dhabi (24.4539° N, 54.3773° E). For a moving robot, deployment would supply its GPS position, speed and direction continuously.

02 · Look ahead

The orbital calculation projects satellites forward and estimates when a tracked satellite drops below 10° above the horizon. Your ML model separately uses position, movement, signal quality and network load to estimate whether a cellular handover is needed.

03 · Prepare, then verify

A deployed controller would combine those forecasts with measured link quality and server readiness. This prototype demonstrates session preparation and transfer, but satellite forecasts and the trained ML model remain advisory.
